# Learning journal

[Learning path](../README.md)

This folder records **your understanding**, not just a list of shipped features. Copy the [learning template](../templates/learning-entry.md) to a file named `YYYY-MM-DD-short-topic.md` and add it to the table.

| Entry | Status | Purpose |
| --- | --- | --- |
| [Starting point](2026-09-28-starting-point.md) | Reference baseline | What exists before working through the course |
| [GitHub Pages: source versus build output](2026-09-29-github-pages.md) | Implementation record | Why Vite needs the custom build workflow |

Leave room for wrong predictions: comparing a prediction with the result is often the most useful part of an entry. Mark a topic “understood” yourself after explaining and varying it; the presence of generated documentation does not establish that you have learned it.

These files are not imported into the public blog. If you later want to publish a learning note, adapt it into `content/` and register its article metadata as described in lesson 8.
